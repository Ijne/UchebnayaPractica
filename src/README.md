# Процедурный прототип контроля партии

Требуется Python 3.12 или новее. Внешних зависимостей нет.

```bash
cd src
python main.py example_input.json
```

Входной JSON содержит партию, измерения и нормативы. Для примера программа
обнаружит превышение температуры 85 °C, сформирует отклонение и присвоит
протоколу статус `требует решения технолога`.

Функции `validate_measurements`, `assess_batch_conflicts` и
`form_batch_protocol` соответствуют автоматизируемым операциям BPMN-модели.
Собственные классы и глобальные изменяемые данные не используются.
